项目把自然语言问询、业务办理入口和人工客服协作连成一个保留上下文的流程。它源于 CNSCC324 六人课程项目，并扩展为可登录、多用户、可在线演示的服务门户。

## 用户交互功能

- 自然语言询问与追问，按当前消息选择中文或英文；检查实际输出语言，必要时进行一次有时间限制的模型纠正。
- 回答生成一段显示一段，避免等待全文；办理按钮与后续问题在回答完成后出现。
- 个人账户、完整聊天记录、侧边栏历史检索与重命名，新建对话后可回到旧对话。
- 社会银行六类业务，学生模式增加助学奖助，合计十一个演示窗口；从回答进入表单，核对并确认后生成办理记录。
- 正常聊天中一键转人工，原对话上下文随工单保留。
- 客户查看自己的记录，客服端接单、回复和结束工单；后端检查角色、归属及工单分配。
- 不同电脑连接同一服务，每三秒同步可见页面；新消息到来时保留客服正在输入的回复。

## AI 接入

接入 DeepSeek API，将对话历史、结构化知识和六个允许的工具结合起来。工具提供 FAQ、产品和网点信息，或准备业务窗口；模型不会自行提交请求。保留来源、工具、调用次数、用量及错误信息，区分在线模型和离线应急模式。

项目没有训练新模型，没有使用真实银行接口，所有金融产品、账户申请和转账均为虚构演示。

## 已有证据

133 项 Python 测试和前端流程检查通过；早期版本的 80 条自编离线评测中，78 条可评测检索问题有 72 条在前 3 项找到目标 FAQ（92.3%），离线关键词代理通过率为 57/80（71.25%）。这些指标不等于整体回答准确率。版本 2.2.2 修复了在线语言跟随问题，修复后 10 轮真实 API 检查通过，其中一轮触发语言纠正。原失败样例与修复后结果均保留，详见 [评测说明](docs/evaluation.md)。
